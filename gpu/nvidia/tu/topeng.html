Engine Topology

You can directly query all engines present on your GPU via MMIO reads, you read 64 registers starting from 0x022700 to 0x0227FC with a 4 byte stride

TOP_INFO_ENGINE_TYPE

Identifies what kind of engine is being described

MMIO base is not always correct, on Turing SEC2 base is not updated, whatever value you read for SEC2 MMIO base always hardcode at 0x840000

TOP_INFO_DATA

Provides the MMIO base address and optional fault ID for the engine

TOP_INFO_ENUM

Provides the logical indices for engine management

Engine Type Mapping

The Type field from the TOP_INFO_ENGINE_TYPE register determines the engine class. Note that some types include an Instance field to distinguish between multiple identical engines (eg multiple NVENC engines)

Discovery Logic

The driver typically expects a sequence of packets for each engine like

  1. ENGINE_TYPE Identifies the hardware block.
  2. DATA Provides the MMIO offset and fault ID.
  3. ENUM Provides the logical indices for interrupts, resets, and runlists.

If a register reads 0x00000000 (NOT_VALID), it is skipped. If the MSB (bit 31) is set that entry is also skipped.
