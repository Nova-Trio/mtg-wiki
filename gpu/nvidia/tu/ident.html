GPU Identification

Make sure your GPU is exposed to the VM, take note of IOMMU setup, if developing for linux make sure nouveau or nvidia drivers arent using the gpu

Vendor ID for NVIDIA is 0x10DE, the device ID can be checked with lspci, the GPUs come with BARs:

  • BAR0 : 16MB; GPU registers
  • BAR1 : varies; VRAM aperture
  • BAR2 : varies; PRAMIN aperture

BAR1 depends if you have ReBAR, there are ways to enable it on a Turing card but if disabled BAR1 is usually 256MB, otherwise the size will be your VRAM size. To access all your VRAM without ReBAR there are registers to write to which change addresses exposed which we will get into later. You can only read and write to a 256MB area of VRAM at a time. PRAMIN is your aperture into GPU instance memory sometimes refered to as RAMIN, it is used for example managing GPU MMU page tables, it is not resized with ReBAR.

Map BAR0 and we will go over few important registers in an early stage, 0x000000 aka NV_PMC_BOOT_0 is used to READ chipset architecture and revision, important to determene if the card is TU1xx or TU11xx when loading firmware

Boot0 register

To read chipset you mask the boot0 value with 0x1ff00000 and shift right by 20 bits, to read the revision you mask boot0 with 0x000000ff

{% highlight c %} chipset = (rd32(0x000000) & 0x1ff00000) >> 20; revision = (rd32(0x000000) & 0x000000ff); {% endhighlight %}

Every turing chip begins with 0x16? To determene if the card architecture is Turing you have to mask chipset with 0x1f0 which will clear the variant bits like

{% highlight c %} if((chipset & 0x1f0) == 0x160) // Turing architecture {% endhighlight %}

vGPU mode

vGPU allows partitioning of the GPU resources between multiple virtual machines, if its active initialization is done differently trough the hypervisor because of the restricted access to MMIO. Value is found on boot1 register 0x00030000 aka NV_PMC_BOOT_1


Boot1 register

Bit 8 is legacy indicator, 0 means REAL (physical hardware), 1 is virtualized, you should read from the bits [17:16] which can be

  • 00 : No vGPU
  • 01 : Paravirtualized vGPU
  • 10 : SR-IOV Virtual Function

It is up to you if you want to support vGPUs

There is also a STRAP register, usually you should use it to read the crystal frequency but historically it was used for other stuff. The register is at offset 0x101000, by masking it with 0x00400040 you can determene the crystal frequency as

  • 0x00000000 : 13500KHz (27.0MHz / 2)
  • 0x00000040 : 14318KHz (NTSC, 4 * 3.579545MHz)
  • 0x00400000 : 27000KHz (Most common)
  • 0x00400040 : 25000KHz (Sometimes used)

You should not assume this value or hardcode it, it is used for gpu timing, display timing and the engine clocks
