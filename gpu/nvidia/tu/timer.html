GPU Timer

NVIDIA includes a programmable timer PTIMER which is used for performance profiling, job scheduling and more, it is a high resolution 64bit timer driven by the numerator and denominator of the crystal.

Reading the time

The GPU exposes 2 32bit registers 0x009400 aka NV_PTIMER_TIME_0 and 0x009410 aka NV_PTIMER_TIME_1,

NV_PTIMER_TIME_0

NV_PTIMER_TIME_1

You read the timer by sampling TIME_1 and TIME_0 in a loop until TIME_1 matches a reread and placing both halves in a u64 timestamp, like

{% highlight c %} do{ high = rd32(TIME_1); low = rd32(TIME_0); } while (high != rd32(TIME_1)); return ((u64)high << 32) | lo; {% endhighlight %}

Waiting and polling

You will frequently need to poll the GPU registers until specific status bits are set a poll like while (!(rd32(REG) & MASK)); is dangerous since if the GPU hangs the CPU core will lock up.

The driver solves this by either using deadlines or checking if the hardware timer is frozen, or both. On every polling iteration you should test if the deadline has expired and verify that the gpu clock is not frozen like

{% highlight c %} current_time = read_timer(); if(current_time == last_time){ return err; }else{ last_time = current_time; } if ((current_time - start_time) > timeout){ return timeout; } {% endhighlight %}

Alarms

When dealing with non blocking waits you must use the alarm, the gpu provides registers 0x00009420 aka NV_PTIMER_ALARM_0; 0x00009100 aka NV_PTIMER_INTR_0; 0x00009140 aka NV_PTIMER_INTR_EN_0 You program a timestamp in ALARM_0 and when the timer mathes value in ALARM_0 the GPU raises an interrupt and your callback function is called

NV_PTIMER_ALARM_0

NV_PTIMER_INTR_0 / NV_PTIMER_INTR_EN_0

To start, you would write the lower 32bits of the timestamp into ALARM_0, enable interrupts by writing 1 to bit 0 of INTR_EN_0, later when recieving an interrupt you must acknowledge it by writing 1 to bit 0 of INTR_0

{% highlight c %} void set_alarm(target_time) { wr32(NV_PTIMER_ALARM_0, (u32)target_time); wr32(NV_PTIMER_INTR_EN_0, 1); } {% endhighlight %}

Because the hardware only has a single 32bit comparator register NV_PTIMER_ALARM_0 the driver would implement a software queue to handle multiple alarms

When the interrupt triggers, acknowledge it, run your callback and reprogram the register with the next pending alarm

{% highlight c %} void handle_alarm_interrupt() { if (rd32(NV_PTIMER_INTR_0) & 1) { wr32(NV_PTIMER_INTR_0, 1); while (queue.earliest_time() <= read_timer()) { queue.pop_and_run_callback(); } if (!queue.empty()) { set_alarm(queue.earliest_time()); } else { wr32(NV_PTIMER_INTR_EN_0, 0); } } } {% endhighlight %}
