BIOS Bootloader

A BIOS reads the first sector of your drive, checks if the last 2 bytes match the boot signature 0x55 0xAA, if they are valid, it loads those 512 bytes into memory at 0x7C00 and executes it. That is your bootloader code, usually 440-446 bytes free for machine code in the bootloader (When counting for MBR partition tables).

{% highlight nasm %} [org 0x7c00] jmp $ times 510-($-$$) db 0 dw 0xaa55 {% endhighlight %}

This above is the simplest bootloader, we set nasm origin to 0x7c00 and pad it to 510 bytes with 0s, last 2 is the boot signature. If the BIOS expects a MBR partition table (most likely when booting on real hardware) your code would look like

{% highlight nasm %} [org 0x7c00] jmp $ times 446-($-$$) db 0 db 0x80 ; bootable flag (0x80 if bootable, 0x00 if not) db 0x00, 0x01, 0x00 ; starting CHS address db 0x71 ; partition type db 0x00, 0x01, 0x00 ; Ending CHS address dd 1 ; starting LBA sector dd 4096 ; total sectors in partition times 16 db 0 times 16 db 0 times 16 db 0 dw 0xaa55 {% endhighlight %}

Bios Interrupts

BIOS offers you couple of interrupt services, which are:

Interrupt number (hex) Service
10 Video
11 Equipment Check
12 Conventional Memory
13 Disk
14 COM
15 System Misc & Extended
16 Keyboard
17 Parallel Printer
18 ROM BASIC / Boot Failure
19 Bootstrap Loader
1A Timer & RTC
here you can find all interrupts documented

The usual step for loading a kernel is to make a 2nd stage bootloader, load it with 0x13 interrupt services, go into protected mode, go into long mode, make a disk and a filesystem driver and load your kernel.

2nd stage bootloader

Interrupt 0x13 AH=0x42 "IBM/MS INT 13 Extensions - EXTENDED READ" is used the documentation says:

Offset Size Field Description
0x00 1 byte Packet size Must be 0x10
0x01 1 byte Reserved Always 0x00
0x02 1 word Sector Count Number of sectors to read (1-127)
0x04 1 dword Buffer Pointer Far pointer to destination memory
0x08 1 qword Starting LBA 64bit LBA of the source sector
